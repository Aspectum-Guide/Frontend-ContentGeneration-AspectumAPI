# План рефакторинга Session Wizard

## Цель

Разделить визард сессии на небольшие шаги и секции, продолжив миграцию интерфейса на общий UI Kit без изменения API и пользовательского поведения.

- `src/pages/generation/SessionWizard.jsx` — около 1685 строк.
- Крупнейшие секции:
  - `SessionWizardAttractionAudioGuidesBlock.jsx` — около 1985 строк;
  - `SessionWizardTagsCatalogStep.jsx` — около 1766 строк;
  - `SessionWizardAttractionsStep.jsx` — около 1501 строки;
  - `SessionWizardAttractionFeedStep.jsx` — около 1112 строк;
  - `SessionWizardInteractiveLocationsStep.jsx` — около 1009 строк.
- Весь каталог `src/pages/generation/session-wizard/` — около 13 500 строк.

## Целевая структура

### `SessionWizard.jsx`

Оставить только:

- общий layout;
- выбор текущего шага;
- навигацию между шагами;
- подключение controller/hooks;
- общие состояния визарда.

### Шаги визарда

Выделить и поддерживать отдельными компонентами:

- `CityStep`;
- `CityInfoStep`;
- `AttractionsStep`;
- `InteractiveLocationsStep`;
- `TagsStep`;
- `PublishStep`.

### Секции достопримечательности

Разделить `AttractionsStep` на:

- форму основной информации;
- редактор feed;
- аудиогиды;
- связанные события;
- commerce;
- теги.

### Общие компоненты

Постепенно вынести повторяющиеся элементы:

- `StepHeader`;
- `WizardNavigation`;
- `AsyncSection`;
- `FieldError`;
- `UploadButton`;
- `LanguageTabs`;
- `SelectionList`.

## Порядок работы

1. Вынести JSX по ответственности без изменения бизнес-логики.
2. Сохранить текущие props и callback-контракты.
3. Перенести локальные обработчики в hooks только после стабилизации структуры.
4. Заменить нативные `button`, `input`, `select`, `textarea` на UI Kit.
5. Добавить или обновить тесты для вынесенных шагов.
6. После каждого крупного шага запускать линтер, тесты и production-сборку.
7. В конце упростить `SessionWizard.jsx` до композиции шагов.

## Ограничения

- Не менять API-контракты.
- Не менять порядок и условия прохождения шагов.
- Не смешивать структурный рефакторинг с изменением бизнес-правил.
- Файловые загрузчики и нативный `<audio>` оставлять нативными там, где UI Kit не даёт эквивалент.

## Ближайший этап

Начать с `SessionWizard.jsx`: выделить один самостоятельный шаг или крупную секцию в отдельный компонент, не меняя поведение. После проверки перейти к следующей секции.
